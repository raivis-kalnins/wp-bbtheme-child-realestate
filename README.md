# WP BBTheme Child — Real Estate

Non-WooCommerce real-estate child theme with a `property` content model, local demo photography, finder filters, grid/list results and property templates.

## Project behavior

Activating this theme selects **Real Estate** mode. WP BBTheme Core deactivates WooCommerce and WP Theme Woo Support (without deleting them), keeping only the non-commerce stack required by the project. Switching back to either Woo store theme activates installed store dependencies again.

## Demo and finder

Starter setup creates/refreshes 10 demo properties across sale/rent, location, type, price, bedrooms, bathrooms, tenure and status data. The finder supports AJAX filtering, keyword/location/postcode search, price ranges, bedrooms, bathrooms, listing type, sorting, grid/list views and saved-search UI.

Included block patterns: property hero, property grid, areas, valuation CTA and proof/trust section.

Version 2.0.0; tested up to WordPress 7.1.
